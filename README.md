# Qismat CV Generator

A sleek, responsive, and customizable single-page web application that allows users to generate professional CVs (resumes) dynamically. Built with vanilla web technologies, the generator features live preview, photo cropping capabilities, and instant PDF export.

## ✨ Features

- **Live Preview:** See your resume update in real-time as you type.
- **Dynamic Content:** Easily add, edit, or remove Work Experience, Education, and References sections.
- **Premium Theme Colors:** Personalize your CV with professional color profiles including Royal Blue, Emerald Green, Burgundy, Modern Slate, and Classic Black.
- **Advanced Photo Uploader:** Includes a built-in image crop and zoom tool utilizing the HTML5 Canvas API, allowing you to perfectly frame your profile picture.
- **Instantly Export to PDF:** Download your finished CV directly as a high-quality PDF using `html2pdf.js`.
- **Fully Responsive:** works flawlessly on both desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure and form elements.
- **CSS3:** Modern styling with Flexbox, CSS Grid, CSS Variables for theming, and responsive media queries.
- **JavaScript (ES6):** Handles state management, dynamic DOM rendering, Canvas-based image cropping, and live updates.
- **html2pdf.js:** A client-side HTML-to-PDF generation library. 

## 🚀 Getting Started

Since this is a client-side only application with no build steps or backend dependencies, getting started is incredibly simple.

1. **Clone the repository** (if applicable) or download the source files.
2. Open the `CV.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Start building your CV immediately!

## 📝 Usage Guide

1. **Upload your Photo:** Click "Choose Image" to upload your profile picture. Use the "Adjust Position & Zoom" feature to drag and scale your photo until it fits perfectly inside the frame.
2. **Select a Theme:** Choose a premium color profile from the provided palette that suits your professional branding.
3. **Fill out Details:** Enter your full name and resume objective.
4. **Add Career History:** Use the "+ Add" buttons to append multiple Work Experiences, Educational achievements, and References.
5. **Generate & Download:** Once you are satisfied with the Live Preview, click the **"🌟 Generate Premium CV"** button to automatically save your document as a PDF. *Note: If you need to start over, you can use the "Reset" button.*
